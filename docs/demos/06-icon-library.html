推荐 🥇 推荐：覆盖最全，与 floating-card 风格契合 🥈 备选：风格相近，图标少一些 不推荐作为主图标库（可保留用于 Element Plus 内部组件）

最终决定建议：Tabler Icons — 视觉统一、覆盖全面、文件大小可接受。
