画布与格子尺寸切换的动画方案

用户调整 cell size 或画布尺寸时，三种过渡效果对比。请挑一个，或告诉我要不要混搭。

每个 demo 下方点击三档格子尺寸 12 / 18 / 24px 即可触发动画。

— — —
01

方案 A · 整体淡出 → 重排 → 淡入

画布整体 opacity 降到 0，瞬间完成尺寸/格子变更，再淡入。最稳的"看不到中间状态"路线。

cell size
实现简单 看不到错位 缺点：切换有"中断感"，节奏稍慢
— — —
02

方案 B · 画布与元素同步平滑形变

画布的 width/height/background-size 与每个元素的 left/top/width/height 用同一条 ease 曲线一起动。最有"活物"感。

cell size
视觉最自然 用户能"看懂"格子变了 缺点：元素多时性能压力大；过程中可能短暂越界
— — —
03

方案 C · 栅格隐去 → 形变 → 栅格回来（推荐）

先把栅格线淡掉（视觉噪音降低），画布与元素平滑形变，结束再让新栅格淡入。兼具 A 的克制 + B 的连续。

cell size
切换观感最克制 视线聚焦在元素上 缺点：实现略复杂，时序要调好
