说明

共同点：grip 从悬浮在边框外改为内嵌（紧贴上边框下方）；保留 4 个角点和右下角 size badge；点击区域不变（grip 容器 padding 撑大热区到 ~20×16px）。
方案 A：完全裸的 6 个圆点 + cursor:grab。与参考图最接近。
方案 B：默认裸点；鼠标悬停时浅紫色背景圆角矩形作为可点提示。元素小到 grip 接近角点时容易和角点视觉混淆，hover 提示更明确。
风险评估：元素高度 < 16px 时（极小元素），grip 会和 size badge / 四角点叠在一起。可以在元素高度 < 6 cells 时自动把 grip 移到元素外（小元素 fallback 用现状 X 样式）。
