操作说明
  • 没有独立"线条"元素 — 出门证里的所有横线都是字段元素自己的 border-bottom。下划线由"字段"承载，跟字段一起移动、一起对齐。
  • 右栏新增"边框"控件：田字格形状的 4 方向切换（上/右/下/左独立显隐）+ 粗细 / 样式 / 颜色。点上面的"上 / 左 / 右"试试 → 画布上的"提货单位"元素对应方向就出边框了。
  • 内边距：4 个 px 数字输入，控制元素内容到自身边框的距离。
  • 移动元素：顶部 ⠿ grip 按钮（飞书仪表盘风）拖动。调整尺寸：4 条边 + 4 个角的 hit-zone。编辑内容：中心单击。
  • 栅格默认隐藏，点 Header ⊞ 模拟拖拽 或 hover grip 按钮才淡入。
  • 选中态改用 outline（不覆盖元素自己的 border 配置）。
